# 履歴書メーカー（外国人向け）

日本の会社に応募するための履歴書を、スマホだけで作れるWebアプリです。
第一の利用者は、フィリピン出身で日本で就職活動中の優子さん。
YOLO JAPANへの改善提案（受付 INQ-2026-00504）の実装を待たず、自宅AI町工場側で作りました。
v1（2026-11-17）に続き、競合調査（`research-competitors-20261118.md`）をもとに v2 へ改修（2026-11-18）。

## v2 の変更点

1. **外国人専用項目を追加**：国籍／在留資格（選択式＋自由記入）／日本語レベル（N1〜N5相当・日常会話レベル等の選択式）／
   その他の言語スキル（言語名＋レベルの行追加式）。印刷では、入力がある場合のみ本人の基本情報の下に
   2項目ずつ横並びの表で表示し、厚労省様式の標準項目の並びは崩していません。
2. **入力言語を5言語に拡大**：日本語 / English / Tagalog / **Tiếng Việt（ベトナム語）** / **Bahasa Indonesia（インドネシア語）**。
   出力される履歴書は常に日本の様式（日本語）のままです。
3. **写真の位置・大きさ調整**：アップロード後に、証明写真の枠（縦4×横3）の中でドラッグで位置を動かし、
   スライダーで拡大・縮小して切り抜き位置を決められます。元の写真は端末内に保持され、いつでも戻せます。
   従来の自動縮小（幅480px）保存もそのままです。
4. **入力チェック**：プレビュー・印刷の前に、必須項目（氏名・フリガナ・生年月日・現住所・電話番号）の未入力、
   電話番号・メールアドレスの形式、学歴・職歴の年月順序をチェックし、UI言語で注意を表示します。
   注意は表示のみで、印刷は止めません。
5. **例文を22本→28本に拡充**：業種に「建設」を追加（志望動機2・自己PR2）、介護の志望動機に
   「初任者研修を活かす」1本、工場の自己PRに「検品が得意」1本を追加。全例文に5言語の対訳説明付き。

やらなかったこと（意図的な見送り）：自由文の自動翻訳（外部送信が必要なため）、会員登録、サーバー保存、
職務経歴書、複数履歴書の保存。

## 使い方

1. `index.html` をスマホのブラウザで開く（GitHub Pagesに置けばURLで開ける。v1は公開済み：
   https://naoki-satou.github.io/rirekisho-maker/ ※v2への差し替えは本人の確認後）。
2. 画面上部のボタンで表示言語を切り替える：**日本語 / English / Tagalog / Tiếng Việt / Bahasa Indonesia**
   - 切り替わるのは入力画面の言葉だけ。出力される履歴書は常に日本の様式（日本語）です。
   - 在留資格・日本語レベルなどの選択式項目は、選ぶと言葉に関係なく日本語の正式名称で履歴書に出ます。
3. 上から順に入力する。入力内容は**自動保存**されるので、途中で閉じても続きから入力できる。
4. 志望動機・自己PR・本人希望欄は、**業種別の例文**から選んで入れて、あとから直すのが早い。
   - 業種：汎用・介護・工場・飲食・清掃・販売・建設
   - 例文には、その文が何を言っているか UI言語での短い説明が付いている。
5. 顔写真は「写真を選ぶ」からアップロード。自動で小さくして保存し、印刷にも反映される。
   位置が合わない場合は「写真の位置・大きさを調整」で枠に合わせられる。
6. 「プレビューを見る」で履歴書の形を確認 →「印刷・PDF保存」で印刷画面を開き、
   「PDFに保存」を選べばPDFファイルになる。プレビュー・印刷の前に入力チェックの結果が出る。

## プライバシー

- データは**ブラウザ内（localStorage）にだけ**保存されます。外部送信は一切しません
  （コード内に通信処理がないことをテストで確認済み）。
- 写真も端末の中だけ。幅480pxに縮小して保存するので容量を圧迫しません。
- v1で保存したデータはそのまま引き継がれます（保存キーは v1 と同じ `resumeAppDataV1`）。

## 様式について

- 現在の公的な標準である**厚生労働省の履歴書様式例（2021年4月公表）**に合わせています。
  - 旧JIS様式は2020年に廃止。押印欄なし、性別は任意記載、
    通勤時間・扶養家族・配偶者の欄は設けない、が現行の標準です。
- 項目：作成日（○年○月○日現在）／フリガナ・氏名／生年月日（満年齢を自動計算）／性別（任意）／
  顔写真（縦40mm×横30mm）／現住所・電話・E-mail／連絡先（別の場合のみ）／
  **国籍・在留資格・日本語能力・その他の言語（v2追加、入力時のみ表示）**／
  学歴・職歴（「学歴」「職歴」の見出し行と「以上」で締める標準の形）／免許・資格／
  志望の動機／特技・好きな学科・アピールポイント（自己PR）／本人希望記入欄
- 学歴・職歴・免許資格・言語スキルは行の追加・削除ができます。年は西暦入力です。
- 印刷はA4判。記入量が少ない場合は1枚、多い場合は2枚に流れます（厚労省様式もA4・2枚が標準）。

## 検証結果（2026-11-18、v2）

- Node + jsdom による自動テスト **76項目すべて合格**（`tests/test.js`、`node tests/test.js` で再実行可能）：
  - v1機能の回帰：localStorageからの復元、言語切替、行の追加・削除、例文の挿入、
    入力→プレビューへの即時反映、自動保存、満年齢の自動計算（検証値：55歳）、
    写真データのプレビュー・シートへの埋め込み、印刷CSS（@page A4）の存在、
    外部スクリプトなし・通信処理なしの確認。
  - v2機能：I18N 5言語のキー完全性、全例文の5言語対訳の存在、在留資格・日本語レベルの選択肢と
    言語切替時のラベル追随、外国人項目のシート表示（入力時のみ）と非表示（未入力時）、
    言語スキルの行追加とシート反映、入力チェック（未入力・形式・年月順序の各ケース、
    問題があっても印刷が実行されること）、写真調整の切り抜き計算（拡大1倍・2倍）、
    切り抜きの確定と「元の写真に戻す」、v1保存データ（写真のみ）からの引き継ぎ。
- WeasyPrintでシートを描画し、A4判・罫線・各欄の配置を目視確認。
  - 記入量の少ないサンプル（外国人項目も入力）：**A4・1枚**に収まる。
  - 学歴・職歴を多く書き、例文全文を入れたサンプル：A4・2枚（厚労省様式の標準範囲）。
    外国人項目の追加で軽いサンプルが2枚化しないよう、項目表を2項目横並びにし、
    自由記入欄の最小高さとシート余白を微調整済み。
- 未検証：実機ブラウザでの写真アップロード→縮小・位置調整（Canvas／ドラッグ操作）はコード確認と
  jsdom上の計算・確定処理の確認のみ。公開後に優子さんのスマホで実地確認するのが確実です。

## 未対応・今後の課題

- **AIによる文章生成・自由文の自動翻訳は入れていません**：外部APIへの送信が必要になり、
  「外部送信なし」の約束と両立しないためです。代わりに例文＋対訳の方式を拡充しました。
- 和暦（令和など）での年月入力・表示には未対応（西暦のみ）。日本の採用現場では西暦も一般的です。
- 職務経歴書（履歴書とは別の書類）は対象外（v2でも見送り）。
- 複数の履歴書の保存・複製は対象外（v2でも見送り）。
- GitHub Pages の v1 → v2 差し替えは未実施（本人の確認待ち）。
